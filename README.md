# Basem Mahmoud Portfolio

Immersive, dark-themed robotics and AI engineering portfolio inspired by the SOHub-style digital experience.

## Run locally

Open `index.html` in a browser from the project root.

## Files

- `index.html` — page structure and content
- `styles.css` — visual identity, responsive layout, micro-interactions
- `script.js` — interactive drone motion, parallax, smooth inertia-like scrolling
